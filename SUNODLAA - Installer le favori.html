SUNODLAA pour suno.com

Un lecteur plus joli par-dessus suno.com : tes espaces de travail, lecture enchaînée, paroles en karaoké. C'est le lecteur de Suno qui joue, rien n'est téléchargé.
  1. Affiche la barre de favoris : Ctrl + Maj + B
  2. Glisse ce bouton dans la barre de favoris :
    ♪ SUNODLAA
    ⤴ Ne clique pas ici : glisse-le dans la barre de favoris.
  3. Va sur suno.com (connecté) et clique sur le favori ♪ SUNODLAA.
    Le bouton ✕ ou Échap le ferme ; le favori ou le bouton rose le rouvre.
Mise à jour : quand je t'envoie une nouvelle version, rouvre cette page et reglisse le bouton dans la barre (supprime l'ancien favori).
